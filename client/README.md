
# Salon FAQ Chatbot — Frontend

This directory contains the React and Vite web interface for the Salon FAQ Chatbot demonstration project.

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will display the local URL in the terminal, usually:

http://localhost:5173

The backend must also be running from the `server` directory for the full application to work.

See the [main project README](../README.md) for backend setup, environment variables, WhatsApp configuration, security notes, and demo limitations.

This project uses a fictional salon and illustrative starting prices for demonstration purposes only.
